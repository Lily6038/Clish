# Clish mod development goals

Clish is a mod for Minecraft 1.21.11 Fabric. It's purely a client-side mod that allows players to create, edit and execute their own shell-like scripts. There are five main goals for the mod:

1. **Scripting**: The mod should allow players to create and execute shell-like scripts. The scripts should be able to call any commands that's available in the game, including commands that are added by other mods. It also provides a way to execute scripts from the game's command line, accepting arguments. There should be a way to create and edit scripts in-game, so a text editor should be provided; also, players could use their own text editor to create scripts, saving them to a certain directory, where the files can be dynamically loaded into the mod.
2. **API**: The mod should provide kinds of APIs for scripts to interact with the game. For example, the API should allow scripts to get the player's position, health, inventory, etc. It should also allow scripts execute simple tasks that players can do in-game, such as left-clicking, right-clicking, moving the mouse, etc.
3. **Programming**: The mod should provide programmer-friendly grammars for scripts. Variables, branches, loops, functions, structures, etc. should be supported. Also, some useful libs should be provided, such as a string lib, a regular expression lib, a math lib, a time lib, etc.
4. **Configuration**: The mod should provide a way to configure the mod. For example, the mod should allow players to set the interval of the script execution, the timeout of the script execution, etc.
5. **Documentation**: The mod should provide documentation for scripts. Each grammar or API or lib should be documented with a description and a usage example. The documentation should be provided in format of markdown, well-organized, and easy to read.
